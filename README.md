# Arham Cooling Solution - Premium Website

A modern, responsive, conversion-focused website for **Arham Cooling Solution** (AC and Refrigerator Repair & Maintenance Services in Saripura, Alam Nagar, Lucknow).

## 🌟 Key Features

- **Conversion-Optimized WhatsApp Booking**:
  - Interactive service enquiry form validating customer name, 10-digit phone number, service type, Lucknow address, date, and problem description.
  - Generates pre-formatted WhatsApp messages dispatched directly to `+91 63861 18036`.
  - Floating WhatsApp chat button with animated pulse indicator.
  - Floating mobile quick-call button and sticky bottom action bar.
- **Accurate & Trustworthy Content**:
  - Grounded strictly in authentic business details (no fabricated reviews, customer counts, or certifications).
  - Highlights the 4 required pillars: Professional Repair Services, Convenient Booking, AC & Refrigerator Solutions, and Customer-Focused Support.
- **9 Core Services Cards with Direct WhatsApp Enquiry**:
  1. Split AC Repair
  2. Window AC Repair
  3. AC Installation
  4. AC Uninstallation
  5. AC Gas Refilling
  6. AC Servicing & Maintenance
  7. Refrigerator Repair
  8. Refrigerator Maintenance
  9. Cooling Problem Diagnosis
- **Business Identity & Local SEO**:
  - Location: Saripura, Alam Nagar, Lucknow, Uttar Pradesh, India
  - Contact: +91 63861 18036
  - Embedded Schema.org `HVACBusiness` JSON-LD structured metadata.
  - Fast-loading responsive layout styled with Tailwind CSS, Lucide icons, and modern typography (Poppins & Inter).

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

The production output is generated in the `dist/` directory ready for deployment to any web host (Vercel, Netlify, Cloudflare Pages, etc.).
